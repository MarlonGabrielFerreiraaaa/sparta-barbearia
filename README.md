# Sparta Barbearia 
**Autores:** Marlon Gabriel Alves Ferreira e Erick Rafael Passos  
**Tema:** Barbearia Profissional
**Disciplina:** Linguagem de Programação para a Web (LPW) - 2026/2

##  Apresentação do Tema
A Sparta Barbearia é mais do que um lugar para cortar o cabelo; é o refúgio do guerreiro moderno. O projeto oferece uma experiência visual robusta, onde a tradição da navalha encontra a precisão espartana. O site foi planejado para homens que buscam excelência, identidade e força, integrando navegação intuitiva, catálogo de produtos e agendamento direto via WhatsApp.

## Diário de Bordo e Evolução Técnica (Log de Desenvolvimento)

### 06/08/2026 — O Nascimento do Guerreiro
- **Definição de Escopo:** Brainstorming e escolha do tema focado em estética masculina [Histórico].
- **Estrutura Base:** Criação do arquivo `index.html` com a estrutura fundamental do documento.
- **Git & GitHub:** Inicialização do repositório local (`git init`), criação do repositório público no GitHub e realização do primeiro commit estrutural [3, 4].

### 08/08/2026 — Estruturação Semântica Avançada
- **HTML5 Semântico:** Implementação rigorosa de tags estruturais para SEO e acessibilidade, como `<header>`, `<nav>`, `<main>`, `<section>` e `<footer>` [5, 6].
- **Hierarquia de Conteúdo:** Organização de títulos (`<h1>` a `<h3>`) e parágrafos para definir a importância da informação [7, 8].

### 10/08/2026 — Estilização e Box Model
- **CSS Externo:** Criação do arquivo `style.css` vinculado via `<link rel="stylesheet">` [9].
- **Arquitetura Visual:** Aplicação das propriedades de **Box Model** (ajuste fino de `padding`, `margin` e `border`) para garantir o espaçamento ideal entre os elementos [10, 11].
- **Check-in:** Preenchimento da planilha obrigatória da disciplina com o link do repositório [12].

### 12/08/2026 — Layout Moderno com Flexbox
- **Alinhamento Dinâmico:** Refatoração do menu de navegação e das seções principais utilizando **Flexbox** (`display: flex`) [13].
- **Distribuição de Espaço:** Uso de `justify-content: space-between` e `align-items: center` para um design equilibrado e responsivo [14, 15].

### 14/08/2026 — Interatividade e Formulários Funcionais
- **Coleta de Dados:** Implementação do formulário de agendamento utilizando o método `POST` para maior segurança [16, 17].
- **Variedade de Inputs:** Adição de campos especializados como `input type="tel"` para WhatsApp, `input type="radio"` para preferências e `<textarea>` para descrições detalhadas [17-19].

### 16/08/2026 — Expansão Multimeios e Navegação
- **Multi-páginas:** Criação das páginas funcionais `procedimentos.html` e `produtos.html` [Histórico].
- **Componentes Visuais:** Organização dos horários de atendimento em tabelas HTML (`<table>`) e listas de serviços (`<ul>`) para clareza total ao cliente [20, 21].

### 18/08/2026 — Upgrade Profissional ("Nível Hard")
- **Framework Bootstrap 5:** Integração do Bootstrap para garantir um design de alto nível, responsividade total e uso de componentes modernos como cards de serviços [22, 23].
- **UI/UX Refinado:** Adição de imagens profissionais via URLs externas, tipografia personalizada (Google Fonts) e efeitos de hover nos links [33, 49, Histórico].
- **Polimento Final:** Revisão completa do código, remoção de comentários desnecessários e atualização final da documentação para entrega.
